# 替换为主题名称

## 教学 Notebook

## 主材料与改编范围

填写作者、原文入口、具体章节、适用先修和选材理由，说明哪些正文已经阅读。记录来源版本、查阅日期、公开改编许可及署名位置。

说明本地覆盖的范围、对原文的必要修正和本仓库补充的解释、练习或实验。核查 API 的参考资料与主要教材分开列出。

## 当前结论与证据摘要

学习后填写精选结论、依据与限制，链接到 Notebook 对应内容和实际运行记录。保留学习者原有解释与修正；详细推导与教学代码在 Notebook 中维护。

## 关联与来源

填写先修主题、关联材料与一手来源；未解决的问题进入 GAPS。版本相关结论注明查阅日期和实际依赖版本。
